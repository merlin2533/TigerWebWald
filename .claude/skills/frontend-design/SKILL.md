# Frontend Design Skill

## Purpose
Create production-grade frontend interfaces with distinctive aesthetics. Avoid generic AI-generated design.

## Design Thinking First
Before writing ANY code:
1. Understand the context, audience, and purpose
2. Commit to a BOLD aesthetic direction
3. Identify technical constraints
4. Define a memorable differentiator

## Aesthetic Priorities

### Typography
- Use distinctive, characterful fonts — never default to Inter, Roboto, or Arial
- Create clear typographic hierarchy with intentional size, weight, and spacing choices

### Color
- Committed color schemes with dominant colors and sharp accents
- Use CSS custom properties for cohesive theming
- Avoid cliched purple gradients on white backgrounds

### Motion
- CSS animations and scroll-triggered effects
- Meaningful transitions that guide the user
- Performance-conscious animation choices

### Spatial Composition
- Asymmetry, overlap, and unexpected layouts where appropriate
- Intentional whitespace as a design element
- Break grid conventions when it serves the design

### Atmosphere
- Textures, patterns, and creative background treatments
- Subtle details that reward close inspection
- Cohesive visual language throughout

## What to Avoid
- Generic aesthetics and cookie-cutter patterns
- Overused fonts (Inter, Roboto, Arial, system defaults)
- Predictable, context-agnostic layouts
- Gratuitous effects without purpose

## Core Principle
Match implementation complexity to the aesthetic vision. Maximalist designs require elaborate code. Minimalist designs demand precision and restraint. Bold maximalism and refined minimalism both work — the key is intentionality, not intensity.
